# Find File Type 1.7.4 (build 1)

A clearer By Folder view, and a steadier view switcher.

## By Folder is now one list

The By Folder tab used to show a bar chart beside a second list that repeated
the same folders, and the chart drew each folder name above its bar, so it
was hard to tell which name went with which bar.

It is now a single list. Each row shows the folder name, its file count and
its size, with a bar underneath scaled to the largest folder. Long folder and
file names wrap onto a second line instead of being cut off, and hovering
shows the full name.

Only the 10 largest folders show at first, so the "Files in this folder"
section is never pushed far down the page. A **Show all N folders** button
expands the rest, and the list collapses again when you open a different
folder.

## Steadier view switcher

The By Type / By Folder / Dead Symlinks control used to stretch its selection
to the left and snap back every time you changed view or watched folder. It
now changes instantly. The word "View" beside it is gone; the segment names
say what it does.

## Requirements

macOS 14.0 or later. Universal binary.
